# PROTOCOLO CIENTÍFICO OBRIGATÓRIO

**Elegibilidade Central**:
TEA + Componente genético/genômico/molecular + Componente inflamatório/neuroimune + Relação documentada.

- Q1: Participação Humana (S/N) -> E01
- Q2: População/Desfecho TEA (S/N) -> E02
- Q3: Confirmação do TEA (S/N) -> E03
- Q4: Separabilidade TEA (S/N) -> E04
- Q5: Componente genético/genômico (S/N)
- Q6: Componente molecular ampliado (S/N) -> Q5 e Q6 = N -> E05
- Q7: Relevância substantiva genética (S/N) -> E06
- Q8: Inflamação/Neuroimunidade (S/N) -> E07
- Q9: Especificidade do biomarcador (S/N) -> E08
- Q10: Relevância inflamatória (S/N) -> E09
- Q11: Relação Genética-Inflamação (S/N) -> E10
- Q12: Relação pertinente ao TEA (S/N) -> E11
- Q13: Tipo de publicação elegível (S/N) -> E12
- Q14: Idioma/Data (N)
- Q15: Verificação animal final (N) -> E01
