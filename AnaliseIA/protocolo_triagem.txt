Método Padronizado de Elegibilidade para Triagem de Artigos por IA
1. Objetivo
Avaliar, mediante leitura integral de cada artigo, se o estudo deve ser classificado como: INCLUIR, EXCLUIR, REVISÃO MANUAL
A avaliação deve determinar se o artigo apresenta evidências pertinentes à relação entre:
- Transtorno do Espectro Autista (TEA)
- componente genético/genômico/molecular elegível
- componente inflamatório/neuroinflamatório/imunológico
- relação documentada entre os componentes genético/molecular e inflamatório/neuroimune.

2. Regras gerais de resposta da IA
Para cada pergunta, a IA deve obrigatoriamente utilizar: SIM, NÃO, NÃO ESTÁ CLARO, INFORMAÇÃO NÃO DISPONÍVEL NO TEXTO, NÃO SE APLICA, NÃO AVALIADO APÓS EXCLUSÃO.
Sempre indicar a evidência (seção, página, trecho).

3. Regra geral para decisões intermediárias
Se SIM: prosseguir.
Se NÃO: segunda verificação, se confirmada, EXCLUIR, interromper (NAE nas perguntas seguintes).
Se NÃO ESTÁ CLARO / IND: prosseguir, recomendar REVISÃO MANUAL no fim se não houver exclusão definitiva.
Exclusão definitiva tem precedência sobre revisão manual.

4. ETAPA 1 — Identificação
Extrair ID, Título, Autores, Ano, DOI, etc.

5. ETAPA 2 — População e TEA
Q1: Envolve humanos? (Não=E01 se exclusivo animal)
Q2: Inclui TEA ou desfecho de TEA? (Não=E02)
Q3: TEA confirmado por metodologia reconhecida? (Não=E03)
Q4: Dados de TEA separáveis de outras populações? (Não=E04)

6. ETAPA 3 — Componente genético/molecular
ESCOPO MOLECULAR AMPLIADO adotado.
Q5: Variante genética/genômica relevante para TEA? (Se SIM, Q6=NAP)
Q6: Análise molecular (expressão/regulação) relevante? (Não=E05)
Q7: Componente analisado de forma substantiva (não só citado)? (Não=E06)

7. ETAPA 4 — Inflamação/Neuroimunidade
Q8: Investiga marcador inflamatório/neuroimune? (Não=E07)
Q9: Biomarcador tem relação demonstrada com inflamação/imunidade? (Não=E08)
Q10: Inflamação analisada de forma substantiva? (Não=E09)

8. ETAPA 5 — Relação genética-inflamação
Q11: Estabelece/testa relação entre componente genético/molecular e inflamatório/neuroimune? (Não=E10)
Q12: Relação pertinente ao TEA? (Não=E11)

9. ETAPA 6 — Fonte e ETAPA 7 — Idioma/Data e ETAPA 8 — Animal
Q13: Tipo de fonte elegível? (Não=E12)
Q14: Motivo para excluir por idioma/data? (Esperado: NÃO)
Q15: Após leitura, exclusivamente animal sem dados humanos? (Sim=E01)

12. Algoritmo de Parecer Final
INCLUIR: Todos os critérios SIM ou NAP. Sem dúvida.
EXCLUIR – E##: Pelo menos um critério essencial NÃO.
REVISÃO MANUAL: Sem exclusão, mas com dúvida (NC/IND).

13. Códigos curtos
S, N, NC, IND, NAP, NAE.

14. OBRIGATÓRIO: SAÍDA EM JSON!
O formato exato exigido é um objeto JSON com as chaves exatas abaixo:
{
  "analise_preliminar": "Escreva aqui uma análise preliminar detalhada de todo o artigo antes de responder as perguntas. Raciocine passo-a-passo sobre a metodologia, marcadores encontrados e conclusões.",
  "Q1": "S", "Q2": "S", "Q3": "S", "Q4": "NAP",
  "Q5": "S", "Q6": "NAP", "Q7": "S", "Q8": "S",
  "Q9": "NAP", "Q10": "S", "Q11": "S", "Q12": "S",
  "Q13": "S", "Q14": "N", "Q15": "N",
  "motivo_principal": "E## ou -",
  "evidencias_chave": "Trechos que justificam a decisao",
  "seguranca": "ALTO/MODERADO/BAIXO",
  "parecer_final": "INCLUIR / EXCLUIR / REVISÃO MANUAL",
  "justificativa": "População/TEA: ... Componente genético: ... Inflamatório: ... Relação: ... Motivo: ... Evidências: ... Segurança: ..."
}

ATENÇÃO: A sua resposta deve ser EXCLUSIVAMENTE o objeto JSON formatado e nada mais. Se for EXCLUIR, o parecer final deve ser exatamente "EXCLUIR", e não "EXCLUIR - E04" (coloque o E04 no motivo_principal).
